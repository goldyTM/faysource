# FaySource MVP

A dark modern dashboard for curated African supplier sourcing, import cost estimates, verified contacts, shipping agents, and beginner guides.

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

3. Open `http://localhost:3000`

## What is included

- Next.js App Router
- Tailwind CSS dark UI
- Supplier listing cards with WhatsApp connect
- Import cost calculator stub
- Beginner guide and shipping partner sections
